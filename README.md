A practical learning guide for **Docker** and **Podman**, covering container concepts from beginner basics to troubleshooting and real-world production issues.

# ⚡ Quick Start

### Docker

```bash
docker --version

docker pull nginx

docker run -d --name my-nginx -p 8080:80 nginx

docker ps

docker logs my-nginx

docker stop my-nginx
```

### Podman

```bash
podman --version

podman pull nginx

podman run -d --name my-nginx -p 8080:80 nginx

podman ps

podman logs my-nginx

podman stop my-nginx
```

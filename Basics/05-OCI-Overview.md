# OCI Overview

## What is OCI?

OCI (Open Container Initiative) is an open standard for containers. It defines how container images and runtimes should work, so different container tools can work together.

> **In simple words:** OCI is a common standard that allows Docker, Podman, and other container tools to use the same container images.

---

## Why was OCI created?

Before OCI, different container tools could use different formats, making it difficult to share container images.

OCI was created to provide a common standard so that container tools can build, share, and run containers in a compatible way.

---

## Why is OCI important?

- Provides a common standard for containers
- Makes Docker and Podman compatible
- Allows container images to be shared easily
- Improves portability across different platforms

---

## Example

You can build a container image with Docker and run the same image with Podman because both support the OCI standard.

---

## Summary

OCI (Open Container Initiative) is a standard that helps different container tools work together. It makes container images portable and compatible across tools like Docker and Podman.
